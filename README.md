# LIFTBRAND website

Home de liftbrand.com (v2, paleta ciruela). Página estática única, bilingüe ES/EN.

- `index.html`: todo el sitio (HTML, CSS y JS en un solo archivo).
- `fonts/`: Schibsted Grotesk (OFL), alojada en el mismo sitio.

## Desplegar
Importar el repo en Vercel como proyecto estático (sin build). Cada push a `main` despliega.
